Rede Neural Artificial - Fei-Fei Li

Descrição

Este projeto apresenta a reprodução de uma rede neural artificial com uma camada oculta, baseada no código apresentado nos slides da Fei-Fei Li.

A implementação utiliza Python e NumPy para demonstrar os principais conceitos envolvidos no treinamento de redes neurais artificiais.

Arquitetura da rede

A rede neural possui três camadas:

Camada de entrada (Input Layer): 1000 características.

Camada oculta (Hidden Layer): 100 neurônios, utilizando a função de ativação sigmoide.

Camada de saída (Output Layer): 10 neurônios.

O treinamento utiliza 64 amostras e executa 2000 iterações.

Tecnologias utilizadas:

Python

NumPy

Git

GitHub

Funcionamento

O treinamento da rede neural é dividido em cinco etapas principais:

Forward Propagation: propagação dos dados pelas camadas da rede para gerar previsões.

Loss: cálculo do erro entre as previsões e os resultados esperados.

Backpropagation: cálculo dos gradientes para identificar a influência dos pesos no erro.

Gradient Descent: atualização dos pesos utilizando os gradientes calculados.

Iterações: repetição do processo para tentar minimizar o erro.
